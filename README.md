# タスク管理アプリ

やるべきことを登録して、完了・削除ができるシンプルなタスク管理アプリです。

## デモ
[https://naranhuleg1200.github.io/リポジトリ名/](https://naranhuleg1200.github.io/task-app/)

## 主な機能
- タスクの追加
- タスクの完了チェック
- タスクの削除
- (例)ページを再読み込みしてもタスクが残る

## 使用技術
- HTML
- CSS
- JavaScript

## 工夫した点
- (例)完了したタスクの見た目を変えて、一目で分かるようにした
- (例)スマホでも使いやすいレイアウトにした

## 苦労した点・学んだこと
- (例)JavaScriptで要素を追加・削除する方法
- (例)エラーが出たときの原因の調べ方
